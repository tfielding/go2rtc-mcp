# Security policy

go2rtc-mcp can be connected to cameras, home automation and messaging accounts, so security reports
are taken seriously.

## Reporting a vulnerability

Please report privately using GitHub's **Report a vulnerability** button on the repository's
**Security** tab (private vulnerability reporting). Don't open a public issue.

Include what you found, how to reproduce it, and the version (`go2rtc-mcp -version`). You should get
a reply within a week.

## Supported versions

Only the latest release receives fixes.
